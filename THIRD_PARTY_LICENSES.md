# Third-party code

## Awakened PoE Trade

- Source: https://github.com/SnosMe/awakened-poe-trade
- License: MIT, © 2020 Alexander Drozdov (full text: [src/lib/apt/LICENSE](src/lib/apt/LICENSE))
- Upstream commit: see [src/lib/apt/UPSTREAM_COMMIT](src/lib/apt/UPSTREAM_COMMIT)

Used parts:

- `src/lib/apt/parser/*`: item text parser, copied unchanged.
- `src/lib/apt/data/*`: game data lookup. `index.ts` is adapted: loading goes through a
  pluggable `DataSource`; changed lines are marked `// [port]`.
- `src/lib/apt/web/price-check/filters/**`, `trade/pathofexile-trade.ts`, `trade/pathofexile-bulk.ts`,
  `trade/Cache.ts`, `trends/getDetailsId.ts`: copied unchanged.
- `src/lib/apt/web/price-check/trade/RateLimiter.ts`, `common.ts`: adapted (Vue reactivity → Angular
  signals), changed lines are marked `// [port]`.
- `src/lib/apt/web/background/Leagues.ts`: not an APT file — a stand-in exporting `PERMANENT_SC`.
- `src/app/price-check/price-check.ts`, `trade-search.ts`: ports of the logic in `CheckedItem.vue` and
  `TradeListing.vue`;
  `src/app/price-check/bulk-search.ts`: port of the logic in `TradeBulk.vue` and `StackValue.vue`.
- `src/app/core/leagues.ts`: port of `renderer/src/web/background/Leagues.ts`.
- `src/app/core/ninja-prices.ts`: port of `background/Prices.ts`, the trend in `trends/PriceTrend.vue`
  and `related-items/RelatedItems.vue`; the poe.ninja tab also shows what `expected-value/DustValue.vue` shows.
- `src/app/core/item-links.ts`, `src/app/item-check/*`: port of `item-check/hotkeyable-actions.ts` and
  `item-check/ItemInfo.vue`; `src-tauri/src/stash.rs` and `clipboard.rs` `paste_text`: port of
  `main/src/shortcuts/text-box.ts` `stashSearch` and `HostClipboard.restoreShortly`.
- `scripts/make-data-indexes.mjs`: port of `renderer/src/assets/make-index-files.mjs`.
- `public/data/en/app_i18n.json`: APT UI strings.
- `public/data/en/*`, `public/data/item-drop.json`: game data files generated by APT
  (derived from Path of Exile game files, which belong to Grinding Gear Games).
