# Тема «APT» для Price of Exile — порівняння і план

Мета: опційна тема, яка на 90 %+ повторює вигляд Awakened PoE Trade (APT). Price check — ідентичний
і стилем, і розкладкою. Налаштування та інші вікна лишаються нашої розкладки, але з кольорами,
шрифтами й базовими стилями APT. Тема — аддон поруч із застосунком, а не частина основного коду:
вмикається прапорцем збірки (як тема за замовчуванням) або з'являється пунктом у меню.

Джерела: знімки APT 3.29.108 `poe-trade-overlay/docs/screenshots/apt/apt-*.png` (57 шт., README з
відповідністю нашим знімкам) і `STYLE_NOTES.md` (палітра, шрифти, розміри, порядок блоків).

## 1. Що накладається легко

| Що | Як | Чому легко |
|---|---|---|
| Палітра | Наші токени в `src/styles.css` (chrome, panel, raised, well, line, bronze, gold, text, muted, mod…) отримують значення APT під `[data-theme="apt"]`: chrome/well → gray-900 `#1a202c`, panel → gray-800 `#2d3748`, line → gray-700 `#4a5568`, muted → gray-600/500, text → gray-200 `#edf2f7`, gold → `#e4c29a`, good/bad → green-500/red-500… | Шаблони вже користуються токенами (`bg-panel`, `text-muted`, `border-line`) — CSS-змінні Tailwind 4 перевизначаються без зміни шаблонів |
| Шрифти | `--font-display` / `--font-sans` теми → FontinSmallCaps 14/20 для всього UI, Exo 2 SemiBold для чисел у модах, системний sans для дат | Ми теж маємо два шрифтові токени |
| Налаштування, toast, stash search, item check, map check | Наша розкладка + палітра й шрифти APT, кути `rounded` (APT округлює кнопки, поля, чипи; ми — ні: `--radius` теми) | Потрібні лише токени й радіус |
| Тіри, теги | Наші T1/T2 і теги отримують кольори APT (Tier 1 жовта заливка, Tier 2 жовтий контур, crafted синій, corrupted червоний, pseudo сірий) | Окремі класи в одному місці |
| Розташування price check | Уже як в APT (F-58: впритул до панелі, `висота × 986/1600`) | Готово |

## 2. Що потребує роботи в основному коді (перш ніж тема можлива)

1. **Захардкоджені кольори в шаблонах.** У `price-check-panel.html` і подекуди ще — десятки
   `bg-[#2a2219]`, `text-[#8fd493]`, `border-[#6a5a2e]`, `from-[#a7823f]` тощо. Їх треба замінити на
   токени (наприклад `--color-selected`, `--color-positive-soft`, `--color-fractured`,
   `--color-button-primary-from/to`), інакше тема їх не перефарбує. Вигляд нашої теми не змінюється.
2. **Механізм тем і аддонів** (мала зміна, корисна й без APT):
   - налаштування `theme` (Overlay → Theme) і атрибут `data-theme` на `<html>` у всіх вікнах;
   - реєстр тем `src/app/themes.ts`: список тем, кожна дає CSS і, за бажанням, власний компонент
     price check;
   - `popup-window` показує компонент price check теми через `NgComponentOutlet`; без теми — наш;
   - розмір вікна price check береться з теми (APT: 460 px завширшки, на всю висоту гри).

## 3. Що потребує окремої розкладки (не накладається)

Price check APT влаштований інакше, ніж наш (мікс A+B), тому тема дає свій шаблон над **тією самою
логікою**: `AptPriceCheck extends PriceCheckPanel` з власним `templateUrl` (усі сигнали, фільтри,
пошук, bulk, poe.ninja, related беруться з базового класу).

| Блок APT (згори донизу) | У нас зараз | Що робити |
|---|---|---|
| Заголовок 24 px: «⇄ 359», ліга по центру, хрестик | Заголовок з меню ліги й курсом | Шаблон теми: те саме вікно, інший вигляд; меню ліги лишаємо (в APT ліга в налаштуваннях) — питання 3 |
| Одна колонка 460 px на всю висоту гри | Дві колонки, 960 px, висота за вмістом | Шаблон теми + розмір вікна з теми |
| Рядок назви: «Category: Boots» (кнопка → база) і «Not Corrupted / Corrupted» праворуч | Шапка з назвою, базою, перемикачами | Шаблон |
| Рядок poe.ninja: «іконка → N × іконка валюти», тренд «⌃⌃ 50 %», «Last 7 days», міні-графік | У шапці праворуч | Шаблон; дані ті самі |
| Чипи: «Item Level: 86», «2 of 6, stats» (згортає фільтри), посилання, стек | Чипи в шапці | Шаблон |
| Вкладки Pseudo / Base item (лише ці дві) | Pseudo / Mods / Base item | Наш Mods лишити третьою вкладкою або сховати — питання 2 |
| Рядки статів у два рядки: чекбокс · текст · min max; під ним теги й тіри «Tier 1» | Один рядок, тір зліва, групи з заголовками | Шаблон (групи й «Σ Mods» сховати; APT показує джерела під рядком при «Mods») |
| Низ фільтрів: «Collapse ⌃», перемикачі Hidden і Mods | Hidden і Σ у своїх місцях | Шаблон |
| Search / Trade ↗, далі «Matched: N · Merchant Only · Trade» і таблиця Price · iLvl · Listed, ціна текстом «4 alch», смугасті рядки | Права колонка, іконки валют | Шаблон; ціна текстом |
| Bulk: сіра примітка про Currency Exchange, кнопки chaos/divine з лічильниками, Price · chaos/bulk · Stock · Fulfill · Listed, «Market Ratio» | Bulk з іконками | Шаблон |
| «You have × 1 → 18 chaos · Stack × 10 → 179 chaos» у пунктирній рамці | Рядок «You have» | Шаблон |
| Related items **поза вікном**, збоку до центру екрана, на напівпрозорому тлі | Ліва колонка | **Найскладніше**: наше вікно непрозоре й одне. Варіанти: (а) прозоре вікно ширше на панель related, (б) окреме маленьке вікно поруч, (в) related усередині колонки — питання 4 |
| Підсвітка місця курсора (білий напівпрозорий круг) і затемнення гри, поки оверлей активний | Немає | Не робити (потребує повноекранного прозорого вікна) або відкласти |
| Вкладка «Rate limiting» унизу | Футер з лімітами | Шаблон |

Item check, map check, stash search — за побажанням лишаються нашими (лише палітра), хоча й там APT
схожий: map check — рядки з кольоровою заливкою червоний/помаранчевий/зелений за позначкою (у нас
кольоровий текст) — легко, якщо захочеш.

## 4. Аддон: де живе і як підключається

- Код теми: `addons/apt-theme/` — CSS токенів, шрифти, компонент `AptPriceCheck` з шаблоном, реєстрація
  теми. Основний застосунок про аддон не знає, крім реєстру тем.
- Підключення при збірці: `npm run build:apt` / `tauri build --config …` з Angular-конфігурацією
  `apt`, де `fileReplacements` підміняє `src/app/addons.ts` (порожній список) на файл, що імпортує
  аддон. Два прапорці: «додати тему в меню» і «зробити темою за замовчуванням».
- Звичайна збірка аддон не включає зовсім (жодного байта в бандлі).
- Розробка — у цій теці-лабораторії (`price-of-exile-apt-theme`, гілка `apt-theme`, push вимкнено);
  результат переноситься в основний репо: спершу пункт 2 (токени і реєстр тем) окремими комітами, потім
  `addons/apt-theme/` — питання 1.

## 5. Порядок робіт

1. Токени замість захардкоджених кольорів (основний код; наш вигляд без змін — перевірка знімками).
2. Налаштування `theme`, `data-theme`, реєстр тем, вибір компонента price check, розмір вікна з теми.
3. Аддон: палітра, шрифти, радіус → усі вікна в кольорах APT.
4. `AptPriceCheck`: шапка, poe.ninja, чипи, вкладки, рядки статів, низ фільтрів, результати, bulk,
   стек, related (обраний варіант), футер.
5. Збірка з прапорцями, пункт меню.
6. Перевірка: ті самі сценарії, що в `docs/screenshots/apt`, знімки нашої теми поруч зі знімками APT,
   поки не збігатиметься на око (кольори — точно за піпеткою).

## 6. Питання до власника

1. Аддон — тека `addons/apt-theme/` в основному репо (не потрапляє в збірку без прапорця) чи окремий
   репозиторій?
2. У price check APT немає нашої вкладки «Mods» (лише Pseudo / Base item, а моди видно через перемикач
   «Mods»). Сховати її в темі (ідентично APT) чи лишити третьою вкладкою?
3. Меню ліги в заголовку: в APT ліга лише в налаштуваннях. Прибрати в темі чи лишити?
4. Related items: (а) прозоре ширше вікно, як в APT; (б) окреме вікно поруч; (в) усередині колонки?
5. Шрифти: Fontin і FontinSmallCaps (Jos Buivenga) та Exo 2 (OFL) можна поширювати; кириличний
   FrizQuadrata в APT — комерційний шрифт, його не беремо, замість нього вільний аналог для кирилиці.
6. Знімок `apt-settings-general.png` містить твій акаунт, `apt-settings-debug.png` — версію Windows:
   не комітити їх, обрізати чи замазати?
